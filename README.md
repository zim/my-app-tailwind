# Next.js Portfolio & Applications

A modern portfolio website featuring multiple web applications built with Next.js, React, TypeScript, and Tailwind CSS.

## 🚀 Features

- **Portfolio Homepage** - Animated landing page with GSAP animations
- **Todo Lists** - Collaborative todo management with real-time updates
- **Budget Tracker** - Personal budget management application
- **Interactive CV** - Professional resume with print functionality
- **GSAP Demo** - Animation showcase and demos
- **AI Chatbot** - Interactive chatbot interface
- **D3.js Demo** - Data visualization examples
- **Real-time Collaboration** - WebSocket-powered collaborative features

## 🛠️ Tech Stack

- **Framework:** Next.js 15.3.4
- **Language:** TypeScript
- **Styling:** Tailwind CSS
- **Animations:** GSAP 3.13.0
- **State Management:** Zustand
- **Real-time:** WebSockets
- **Data Visualization:** D3.js

## 📦 Installation

1. Clone the repository:
```bash
git clone https://github.com/yourusername/nextjs-portfolio.git
cd nextjs-portfolio
```

2. Install dependencies:
```bash
npm install
```

3. Start the development server:
```bash
npm run dev
```

4. Open [http://localhost:3000](http://localhost:3000) in your browser.
